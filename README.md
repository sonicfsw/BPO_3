# Описание работы программы

Проект реализует иерархию классов для животных на языке C#.

## Иерархия классов

Используется следующая структура наследования:

```text
Animal
├── Artiodactyl
│   └── Cow
├── Dog
├── Horse
└── Cat
```

`Animal` - абстрактный базовый класс для всех животных. Его нельзя создать напрямую, потому что он описывает общее понятие животного. В нем находятся общие свойства: `Name`, `Age`, `Weight`.

`Artiodactyl` - абстрактный класс для парнокопытных животных. Он наследуется от `Animal` и добавляет свойство `HasHorns`.

`Cow` - конкретный класс коровы. Он наследуется от `Artiodactyl`, так как корова является парнокопытным животным.

`Dog`, `Horse`, `Cat` - конкретные классы, которые наследуются от `Animal`. Лошадь не наследуется от `Artiodactyl`, потому что относится к непарнокопытным.

## Абстрактные и виртуальные методы

Метод `Talk()` объявлен абстрактным в классе `Animal`, потому что каждое животное издает свой звук. Все конкретные классы обязаны переопределить этот метод.

Метод `PrintProperties()` объявлен виртуальным. В базовом классе он выводит общие свойства животного, а наследники расширяют его и добавляют собственные свойства.

## Конструкторы и деструкторы

В каждом классе описан конструктор. Конструкторы принимают значения свойств и передают общие данные в базовые классы с помощью `base(...)`.

В каждом классе также описан деструктор. В C# деструктор вызывается сборщиком мусора автоматически, когда объект больше не используется. Поэтому в программе он нужен в основном для демонстрации задания.

## Работа программы

В `Program.cs` создается массив типа `Animal[]`. В него помещаются объекты классов, которые можно создать:

- `Cow`
- `Dog`
- `Horse`
- `Cat`

Объекты классов `Animal` и `Artiodactyl` не создаются, потому что эти классы абстрактные.

Для каждого элемента массива вызываются:

- `Talk()` - выводит звук животного;
- `PrintProperties()` - выводит все свойства объекта.

## Запуск

```bash
dotnet run
```
